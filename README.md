# Detección de Fake News

Proyecto de clasificación de texto listo para Google Colab. Incluye EDA, TF-IDF, modelos y SHAP.

## Abrir en Google Colab

- Noticias simuladas reales/fake
- EDA (distribución)
- TF-IDF + modelos (Logistic Regression, Random Forest)
- Evaluación (classification report, matriz de confusión)
- **SHAP** (summary plot)
- Conclusiones
